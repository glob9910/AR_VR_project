# Dźwięki

| Plik | Zastosowanie |
|---|---|
| `bounce.wav` | odbicie piłki od nawierzchni i trawy |
| `rim.wav`, `rim2.wav` | uderzenie w obręcz (dwa warianty, losowane) |
| `backboard.wav` | uderzenie o tablicę, słup i ogrodzenie |
| `swish.wav` | piłka przechodząca przez siatkę |
| `score.wav` | zdobycie punktów |
| `end.wav` | gwizdek – koniec gry na czas |
| `ambient_park.ogg` | zapętlone tło parku (ptaki) |

Odgłosy uderzeń są przestrzenne (`AudioStreamPlayer3D`), a ich głośność i wysokość
zależą od siły uderzenia. Globalną głośność zmienia się w ustawieniach.
Źródła nagrań: `assets/CREDITS.md`.
